## Usage

Stamp wraps all your package managers into a single CLI. Below are guides grouped by task.

### Getting Started

- [Setup](/usage/setup.html) — First-time setup wizard
- [Configuration](/usage/configuration.html) — Config and manifest reference

### Managing Packages

- [Installing Packages](/usage/installing-packages.html) — Install with flags, notes, aliases, groups, and casks
- [Removing Packages](/usage/removing-packages.html) — Remove, uninstall, and untrack with -m and --group
- [Searching Packages](/usage/search.html) — Search across managers, scope with -m, use --group for DNF groups
- [Viewing Package Info](/usage/info.html) — Query package details, JSON output, DNF group info

### Diagnostics & Maintenance

- [Updating Packages](/usage/update.html) — Two-phase (check + confirm), single package, serial mode, outdated/check-update

- [Version Pinning](/usage/hold-unhold.html) — Hold, unhold, list pinned packages
- [System Diagnosis](/usage/doctor.html) — Check managers, manifest, and system compliance
