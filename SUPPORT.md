# Support

## Documentation

Installation, usage, and the full CLI reference live at [gostamp.dev](https://gostamp.dev).

## Bugs and feature requests

Open an issue with the [bug report or feature request form](https://github.com/rossijonas/stamp/issues/new/choose). The forms ask for the details needed to reproduce or evaluate your request.

## Security issues

Do not open a public issue. Follow [SECURITY.md](SECURITY.md) to report a vulnerability privately.

## Contributing

See [CONTRIBUTING.md](CONTRIBUTING.md) for development setup, quality gates, and commit conventions.
